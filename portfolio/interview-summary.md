# Interview Summary

## 專案名稱

LINE AI Customer Service & Student Care Workflow

## 一句話介紹

這是一個針對美容教育場景設計的 LINE AI 客服與學生關懷 workflow 系統，整合 AI 回覆、課程問卷、學生紀錄、提醒任務與後台工作台。

## 為什麼做這個專案

因為服務型小型事業常需要透過 LINE 回覆大量重複問題，同時還要管理問卷、提醒、課後關懷和客戶紀錄。單純 chatbot 無法處理完整營運流程，所以我把它設計成 AI application，而不是只有聊天功能。

## 我負責的工作

- 需求拆解與 workflow 設計。
- LINE Bot webhook flow 設計。
- AI 回覆與 prompt boundary 設計。
- Supabase 資料狀態與 follow-up tasks 設計。
- Admin workbench 的操作流程整理。
- GitHub portfolio 文件、匿名截圖與架構圖整理。

## 使用技術
