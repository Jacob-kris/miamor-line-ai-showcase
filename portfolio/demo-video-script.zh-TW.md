# Demo Video Script

影片不是第一版 public showcase 的必要條件。若要投履歷或面試，可以使用這份 60-90 秒腳本。

## 口語版

> 這是我做的一個 LINE AI 客服與學生關懷系統，情境是美容教育事業常遇到的課程諮詢、問卷收集和後續提醒。<br>
> 我把它設計成不只是 chatbot，而是完整的 workflow：LINE 收到訊息後，後端會判斷目前是 AI 回覆、課程問卷，還是 follow-up 任務；重要資料會寫進 Supabase，店家也可以在 admin workbench 裡搜尋學生、整理紀錄、處理課前提醒和課後關懷。<br>
> 技術上我用了 LINE Messaging API、Vercel Serverless Functions、OpenAI API 和 Supabase。AI 的部分不是讓模型亂回答，而是透過 prompt 邊界、產品規則和資料狀態去控制回覆。<br>
> 這個專案對我來說最重要的是，它展示我可以把一個真實商業流程拆解成可用的 AI application，並用 AI coding tools 協助開發、驗證和整理文件。

## 不要錄到

- 真實 LINE 通知或對話。
- 真實客戶資料。
- `.env` 或 secret。
- Browser address bar 裡的 private URL 或 session token。
- Vercel / Supabase 的 private settings。
